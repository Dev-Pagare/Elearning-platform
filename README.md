# E-Learning Platform Using Django

A full-featured e-learning platform built as a final year project.

## 🚀 Features
- User Authentication (JWT)
- Course Enrollment System
- Chapter & Lesson Management
- Quiz / MCQ System
- Progress Tracking
- Certificate Generation
- Contact Us Page
- Admin Panel

## 🛠️ Tech Stack
- **Backend:** Django 5.2, Python 3.14
- **Frontend:** HTML, CSS, JavaScript, Bootstrap Icons
- **Database:** SQLite
- **Auth:** JWT Tokens

## ⚙️ How to Run
```bash
# 1. Activate virtual environment
venv\Scripts\activate

# 2. Run migrations
python manage.py makemigrations
python manage.py migrate

# 3. Start server
python manage.py runserver
```
